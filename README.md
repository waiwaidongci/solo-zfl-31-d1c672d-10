# 手工织锦纹样排版台

直接打开`index.html`使用。

**基础功能**：网格绘制、色线统计、撤销重做（含分片）、断线风险提示、本地保存、导入/导出 JSON。

**分片拼版**：划片模式下在画布拖出互不重叠的矩形织片，每片可设行列重复与横纵偏移；拼接总预览实时显示版图，相邻织片边界色序不匹配时以红色标出具体缝隙（画布、总预览与列表三处），未处理前无法生成工艺结果；改动画布或分片后已确认结果立即失效。

**织造预算**：按目标幅宽、长度与缩率自动计算补偿后尺寸、排版版数、分片数量、接缝耗损与各色用料，明细随编辑实时更新。

分片、偏移、确认状态与预算参数均会本地保存，刷新或导出再导入后完整还原。
